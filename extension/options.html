Aionda Browser MCP

Connect your AI assistant to your browser.

1. Set up your MCP client

Install Node.js 22 or newer on the computer running Chrome. Add this server to your MCP client's configuration:

{
  "mcpServers": {
    "aionda-browser": {
      "command": "npx",
      "args": [
        "-y",
        "aionda-browser-mcp@0.1.1"
      ]
    }
  }
}

Restart your MCP client. It starts the local server automatically.

Alternatively, install the command globally:

npm install -g aionda-browser-mcp

Full installation guide and troubleshooting →

2. Enable the browser connection

The host, port and token must match your MCP server. Only localhost connections are supported.

Your MCP client can read page content and tab URLs, take screenshots, interact with pages, run JavaScript and upload local files on your behalf. While enabled, the connection follows your active tab. Page data is sent to your local MCP client, which may share it with its AI provider. Enable this only for clients and pages you trust.

Open a normal website. The toolbar badge shows on when connected. Ask your assistant to check browser_status.

To stop access, clear “Enable browser access” and save, or disable the extension. No Aionda account, analytics or cloud relay. Privacy policy · Support
